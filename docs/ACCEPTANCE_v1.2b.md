# v1.2b in-game acceptance

Offline checks prove model behaviour, source boundaries and import availability. They do not prove
appearance, input or native friend and party behaviour. Run these in Farever and report the first failure.

1. Open and close with the panel key in pointer mode and in camera mode. In camera mode the window stays visible but
   cannot be clicked; the menu bar says the pointer is locked.
2. Right-click empty space, the title bar and the menu bar: Fit to design proportions, Reset size and position and
   Close window work. Rows and fields keep their own menus.
3. Browse: sort every column, resize columns, select with the mouse and Up/Down, Enter whispers, Delete hides, Ctrl+F
   searches, right-click a row. Narrow the window below 900 px: the inspector becomes a page with a Back button.
4. People: friends, same realm, search, Invite and Add buttons, add by Farever code, Remove friend with its confirmation.
5. Party: with another player, invite from the Party menu, the strip and People. As a member use Leave in the strip
   (two clicks), the Party menu and People. Confirm the game's normal prompts appear.
6. Rebind the panel key in Settings, General (capture and list). Try a letter without a modifier, then a key the game
   already binds and read the warning.
7. The on-screen button: click, drag, Lock, Transparent, Reset Position, Hide Button and the optional Leave chip.
8. Post, templates, Messages, Settings (all pages) and the Boss loot window.
9. Relay: the menu bar reads Relay connected; clear a bad Steam ID and confirm messaging still connects.
10. Themes (including High Contrast), text size 85% to 150%, and 520 x 360 up to 1440 x 900.
